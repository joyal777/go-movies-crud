# Go Movies CRUD API 🎬

A simple and efficient CRUD (Create, Read, Update, Delete) API built with Golang. This project manages a collection of movies, allowing users to perform basic database operations.

## 🚀 Features
- **GET** all movies
- **GET** a single movie by ID
- **POST** a new movie
- **PUT** update an existing movie
- **DELETE** a movie

## 🛠️ Prerequisites
- [Go](https://golang.org/dl/) (1.18 or higher recommended)
- A tool to test APIs (like **Postman**, **Insomnia**, or **cURL**)
